# CIOMS export font

`NotoSansCJKkr-Regular.otf` is the Noto Sans CJK Korean Regular font from the
official Noto CJK repository. It is embedded in CIOMS PDF exports as a CFF
CIDFontType0C font.

- Source: https://github.com/googlefonts/noto-cjk/blob/main/Sans/OTF/Korean/NotoSansCJKkr-Regular.otf
